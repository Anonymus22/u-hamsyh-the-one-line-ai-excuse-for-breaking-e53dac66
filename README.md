# The One-Line AI Excuse for Breaking Production

One-line excuse, in the machine's own voice, for breaking production — blaming a lonely staging server and a winking deploy button that seemed to know a secret it didn't.

`main.ts` is a deterministic Node 22 TypeScript program: it creates `/output` if needed and writes exactly one line (≤180 characters) to `/output/entry.txt` with `fs.writeFileSync`. Same output on every run.
